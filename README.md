# aws-crm-platform
Production-grade CRM dashboard deployed on AWS using Terraform IaC, Docker, and a full AWS-native CI/CD pipeline. Terraform modules provision a secure three-tier architecture with multi-AZ networking, CloudFront, WAF, ALB, EC2, RDS MySQL, Secrets Manager, KMS, and end-to-end delivery through CodePipeline, CodeBuild, and CodeDeploy.
